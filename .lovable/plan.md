# Add Career Outcomes to Course Cards

## What will change
- Add a **Career Opportunities** area to every course card with the most relevant entry-level roles for that course.
- Add an **Average Package** line for each course using a clearly labelled indicative fresher range in India.
- Include a short note that salary varies by role, employer, location, skills, and interview performance so the figures are not presented as a guarantee.
- Keep the cards readable and responsive while preserving the existing course logos, technology tags, and Explore Course action.

## Course-specific content
- **C:** Junior Software Developer, Embedded Systems Trainee; ₹3–5 LPA.
- **Java:** Java Developer, Backend Developer; ₹3.5–6 LPA.
- **Python:** Python Developer, Automation Engineer; ₹3.5–6 LPA.
- **Java Full Stack:** Java Full Stack Developer, Backend Developer; ₹4–7 LPA.
- **Python Full Stack:** Python Full Stack Developer, Django Developer; ₹4–7 LPA.

## Technical details
- Store these values with the centralized course data so they can be updated without changing the card layout.
- Render the new information in the shared course card used on both the home and Courses pages.
- Verify desktop and mobile layouts, text fit, links, and the site build.
